## What is?

Builds a standalone environment for agentic labeling of C pseudocode generated by Ghidra, specifically for `F.D.N.Y. Firefighter: American Hero`.  Follow steps in `how do?`, come back in a couple days, and wow!  A human readable codebase!

Agents run in a `/loop` against `plan-init.md` to build a sqlite db for tracking work items, setting hypothesis/confidence of assertions, and some other fancy stuff.  A .html page is generated for easy viewing.

Agent workflow summary:
 - search web for baseline context of what the game is
 - look through the codebase for strings similar to context items gained from research
 - decipher symbols, log hypothesis and confidence scores
 - iterate on hypothesis until confidence is sufficient

Throughout the process, confidence weighting ensures agents don't step on each others' toes.  Lightweight agents interface with Ghidra and upload their findings to the database.  A heavier reasoning model chugs through the information, reaches concencus, then sets naming.

## then what

The webpage, database and schema are what the agent came up with, and happened to work perfectly on the first run.  The process may not be repeatable, intent is to capture the artifacts and rebuild with deterministic code if I decide to expand this process to other games.
